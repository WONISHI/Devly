# 0.2.0-preview.1

日期：2026-11-27。macOS ARM64 本地未签名预览，尚非两平台正式发行。

- 汇集实际 API 聊天/Agent、审批/取消、Monaco/Diff、Git/终端、恢复、MCP/Skills/子任务、附件/网页/本地定时任务。
- 未支持平台的项目执行与终端明确禁用并说明原因；不会退回无隔离运行。
- node-pty 延迟加载，缺依赖时保留可启动界面并提示重装；实际安装副本缺失 PTY/SQLite 的错误处理已验证。
- 修复 linkify-it/KaTeX 的本轮生产安全公告，原组件不替换；数学 CSS/字体本地加载。
- 新增当前源码快照、DMG 校验、中文/空格安装路径、旧库迁移和缺依赖验收入口；不以旧 HEAD 替代未提交源码。

Windows 权限隔离/终端和完整安装实测，签名/公证，维护中的 Electron/工具链及既有完整版权通知，新协议/商业搜索/真实视觉等独立验收仍保留。实际通过记录和产物摘要见 [发行验收](./release-acceptance.md)，使用、快捷键与排错见 [使用指南](./user-guide.md)。
