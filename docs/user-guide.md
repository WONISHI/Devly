# Devly 预览版使用与排错

版本：0.2.0-preview.1，2026-11-27。当前交付 macOS ARM64 未签名预览；Windows 代码入口不代表完成 Windows 执行隔离。实际验收与保留项见 [发行报告](./release-acceptance.md)。

## 安装与更新

1. 校对随包 SHA256SUMS，打开 DMG，将 Devly.app 复制到自己的应用目录，退出旧版后运行新副本。
2. 用户数据独立于 .app，默认保存在 ~/Library/Application Support/Devly/storage；不要把该目录当安装缓存删除。先在设置 → 数据与恢复创建备份，再更新应用。
3. 新版会按事务迁移数据库并保留迁移前备份。旧应用遇到更新的数据库版本会拒绝读取，不要反复用旧版覆盖新库。
4. 预览没有 Developer ID 签名和公证；Gatekeeper/企业策略与正式安装分发未验收。遵循系统的来源检查，不关闭系统安全保护，不把本地启动测试视为已获 Apple 信任。

本轮安装测试使用 DMG 的只读挂载副本和临时安装目录，不会替用户永久替换 /Applications 中的程序或个人数据库。没有自动更新服务。

## 第一次使用

- 直接“新聊天”或打开/创建本地项目。项目区和最近会话分开，切换项目/会话保留已保存历史。
- 设置 → 模型供应商，填写名称、协议、API 根地址、模型 ID，通过系统保护输入框保存 Key。根地址按供应商文档填写，兼容 Chat 的地址由应用追加 /chat/completions；不要重复填写该路径。
- 保存并测试连接；文本成功不代表工具/视觉已支持。模型列表不可用时可以手工输入 ID。模型选择器按供应商区分相同模型名。
- 新会话使用选中的模型；已有会话切换供应商涉及历史，必须显式确认。切换本身不发消息，不自动转交给其他供应商。

## 聊天与编程

普通聊天仅接收消息；只读 Agent 可搜索/读项目。在 macOS 选择项目权限“每次询问”，再选择项目 Agent，才能提议修改和命令。原 Confirmation 显示完整参数，每次允许或拒绝；未批准不执行。拒绝、冲突、超时和错误会保留真实记录。

编辑器通过“项目文件”打开，支持标签、保存、未保存提示和外部变更冲突；修改面板与 Monaco Diff 展示实际仓库内容。Git 提交由用户主动触发，不自动推送。Agent 执行记录与用户交互终端分开；终端是项目受限 Shell，不加载个人 shell 配置或提供任意网络/目录访问，不能假定开发机的所有工具都可用。

停止会等待网络、审批及进程收尾；已有修改保留，未知副作用显示待核对。重启不重放旧命令；恢复检查通过后可新建只读继续，不能透明恢复原来的进程。

## 附件、网页与自动任务

附件通过输入框系统选择器导入副本，导入不发网络；发送会把所选文件及已完成的附件历史交给当前模型。文本/图片有大小与类型限制，视觉未知时不发图片；删除待发引用不删除原文件。

网页工具、隔离网页预览与本地定时任务各有独立设置组。网页能力默认关闭，搜索凭据独立；浏览器逐次审批，截图为本地真实产物，不自动声称模型看到了图片。预览只打开已有静态 HTML，不能访问主界面 IPC/Key，不自动运行 npm 或后台服务。

定时任务默认停用，启用即授权按固定 Provider/模型发送必要项目上下文并可能计费；只在应用运行、机器唤醒时检查，只读、限额，不是云服务。macOS 仅关窗口而应用仍在 Dock 运行时任务仍可继续；真正退出后不执行。停止并停用会取消对应运行；备份恢复后需重新启用。详细范围见 [附件、网页与自动化](./web-and-automation.md)。

## 已实现的键盘操作

| 操作 | macOS | 适用条件 |
| --- | --- | --- |
| 发送 / 换行 | Enter / Shift+Enter | 输入框中；IME 组合输入不提前提交 |
| 保存当前文件 | ⌘S | Monaco 编辑器焦点内 |
| 显示/收起交互终端 | ⌘J | 已打开本地项目 |
| 聚焦聊天输入 | ⌘L | 已打开本地项目 |
| 项目文件面板 | ⌘⇧E | 已打开本地项目 |
| Git 面板 | ⌘⇧G | 已打开本地项目 |
| 中断前台终端命令 | Ctrl+C | 终端焦点内，不等于关闭任务或回滚文件 |

对应处理器也接受 Ctrl 修饰键，但 Windows 运行和终端功能未验收，不能据快捷键代码声称两平台已通过。模型选择等其他操作使用实际按钮，不提供尚未实现的快捷键。

## 常见问题

| 表现 | 操作与实际限制 |
| --- | --- |
| 测试连接成功，Agent 失败 | 独立检查工具能力、协议与模型参数，查看真实错误；文本连接不证明工具兼容 |
| 401/403 | 检查保护凭据、端点和权限；不要把 Key 发到聊天/截图/日志 |
| 429 / 超时 / 断流 | 检查服务配额与网络；按实际状态核对后重发，不自动重放副作用 |
| 图片无法发送 | 选择声明支持视觉的模型或移除图片；不静默丢弃图片历史 |
| 项目目录不可用 | 重新选择实际目录；项目记录不是目录权限、也不保证移动后仍有效 |
| 文件已被外部修改 | 先比较/重新加载/保存，应用不会把旧版本静默覆盖磁盘 |
| 终端原生依赖不可用 | 重新安装对应架构的完整应用并重启，保留个人 userData；从源码需按目标 Electron 重建依赖 |
| SQLite 不可用 | 保留当前数据/备份，检查空间、权限和安装完整性，再用重试/数据恢复入口；不要删库“修复” |
| Git / Node / 包管理器未找到 | 环境面板可能只检测 PATH；受限终端仅固定系统工具，不提供个人工具链注入 |
| Windows 无项目执行/终端 | 当前明确禁用，等待真实 Windows 隔离和终端落地；不提供无沙箱回退 |
| 恢复后 Key/定时任务不可用 | 备份不包含 Key，任务默认停用；重新在系统输入框保存并明确启用 |
| 费用未知 | 显示供应商上报用量或明确估算；当前不编造实时价格，以服务账单为准 |

诊断从设置 → 数据与恢复导出白名单摘要；导出不包含 Key 和长日志正文。实际任务错误、调用 ID 和脱敏原始日志分别可查看；不要将个人项目、完整截图或凭据当作必须公开的排错材料。
