# Devly logo variants

用户提供的 Devly 标志经内置图像编辑工具放大后的两种版本，缩小外部留白并保留 D 形开口、圆点与黑白配色。原始桌面文件保持不变。

- `devly-logo-light-v2.png`：白底黑标志。
- `devly-logo-dark-v2.png`：黑底白标志。

深色版用于应用左上角品牌标志。

- `devly-app-icon-dark-v3.png`：上一版圆角应用图标，底板占画布约 70%，保留作对比。
- `devly-app-icon-dark-v4.png`：底板较 v3 放大约 10%，宽高占画布约 77%，保留作外框尺寸对比。
- `devly-app-icon-dark-v5.png`：当前用于 Dock、窗口与安装包的版本，保留与 v4 接近的外框占比，只缩小内部白色标志，增加黑色内边距。

`build/icon.png` 和 macOS `build/icon.icns` 从 v5 圆角应用图标导出。macOS 打包图标与运行时资源均在 electron-builder 中配置。Windows / Linux 已配置 PNG 图标路径，尚需对应平台构建验证。

## 编辑提示

浅色版：将原标志整体等比放大并居中，目标主体高度约为画布的 78–82%，四周保留均衡边距；保留 D 形、右侧开口、圆点相对大小和位置、圆角与描边比例，不添加文字、阴影、渐变或装饰。

深色版：以上述放大版作为尺寸与构图参考，生成白色标志、纯黑背景的对应版本，保持符号形状、圆点和开口，禁止退回原图的小尺寸构图。

以上为编辑目标；生成结果已目视检查，主体明显放大，边缘保留留白。两版属于生成式编辑产物，并非逐像素完全相同的正反色文件。

应用图标 v3 使用内置图像编辑：保持白色 D 形与圆点，在透明画布中央放置黑色圆角底板，四周保留均衡透明边距。已检查实际 Alpha 通道，四角透明；不透明底板宽高约占画布 70%，与先前铺满画布的白色方块相比缩小约 30%。这与最初用于页面展示的 logo 图分开管理。

v4 继续使用内置图像编辑，提示为整体放大原底板与标志、保留圆角和透明背景，目标占比约 80%。实际导出经 Alpha 通道检查，不透明底板宽高占比约 77%，四角和画布边缘透明；此处记录实际测量值而非提示目标值。

v5 使用内置图像编辑，提示为锁定黑色圆角底板，将内部白色 D 形和圆点整体缩小，增加内部留白。导出时用系统 sips 对透明画布进行居中裁切校准，再生成各尺寸 PNG 和 ICNS，使底板宽度占比保持约 77%，避免整体尺寸随生成结果缩小。白色标志相对底板高度由约 72% 降至约 60%，外边缘及四角仍透明。
