The Apache-2.0 upstream notice is retained at [../ai-elements/LICENSE](../ai-elements/LICENSE). Local changes only replace monorepo aliases and apply project Prettier formatting. Exact upstream/local checksums are in [the vendor manifest](../../../../../resources/vendor/ai-elements.json); `pnpm verify:vendor` checks local integrity and `node scripts/verify-vendor.mjs --refresh` compares against upstream.

This record covers avatar, badge, button, button-group, collapsible, select, separator, tooltip, input, textarea and label. It does not assign a blanket license to independently installed Radix or other dependencies.
